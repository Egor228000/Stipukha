# Stipukha (Стипуха) 💰

**Stipukha** — это умный менеджер личного бюджета для Android, который помогает не просто записывать траты, а реально планировать свои финансы. Приложение ориентировано на концепцию "дневного лимита" и автоматического перераспределения средств.

## 🚀 Основные возможности

- **Умный дневной лимит**: Приложение рассчитывает, сколько вы можете потратить *сегодня*, исходя из общего остатка и срока бюджета.
- **Авто-коррекция**: Если вы потратили больше лимита сегодня, приложение автоматически уменьшит лимиты на будущие дни, чтобы вы "дожили до зарплаты".
- **Гибкое пополнение**: При добавлении средств («Пополнил»), сумма равномерно распределяется на все оставшиеся дни, увеличивая ваш ежедневный уровень комфорта.
- **Статистика и аналитика**: 
    - Средний чек.
    - Самые экономные и затратные дни недели.
    - Структура расходов по категориям.
- **Управление периодами**: Легко меняйте общую сумму или дату окончания бюджета — приложение мгновенно пересчитает весь план.

## 🛠 Технологический стек

Проект написан с использованием самых современных инструментов и архитектурных подходов Android-разработки:

- **UI**: Jetpack Compose (декларативный интерфейс).
- **Архитектура**: Clean Architecture + MVI (Model-View-Intent).
- **База данных**: Room (локальное хранилище с реактивными потоками данных через Flow).
- **Навигация**: Navigation 3 (экспериментальная навигация на основе состояния).
- **DI**: Ручное внедрение зависимостей через ViewModel Factories.
- **Параллелизм**: Kotlin Coroutines & Flow.

## 📁 Структура проекта

- `ui/feature_main`: Главный экран с вводом транзакций и индикатором лимита.
- `ui/feature_stats`: Экран аналитики и истории.
- `ui/feature_add`: Настройки бюджета, редактирование параметров и сброс.
- `domain/usecase`: Бизнес-логика приложения (расчеты, управление транзакциями).
- `data/repository`: Слой данных, объединяющий Room и бизнес-логику.

## 📖 Как это работает (Алгоритм)

Приложение использует формулу равномерного распределения:
`Лимит_на_день = Текущий_Баланс / Оставшееся_количество_дней`.

Если вы совершаете перерасход сегодня, ваш `Текущий_Баланс` уменьшается сильнее, чем планировалось, что ведет к автоматическому снижению лимита на завтра. Это создает естественную обратную связь и помогает дисциплинировать свои траты.
